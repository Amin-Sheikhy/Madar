مَدار یک محیط یادگیری و پژوهش فارسی‌محور و محلی برای ویندوز است که داشبورد یادگیری، ساختار دوره‌ها و شواهد تسلط، سازمان‌دهی دانش علمی، نقشه مهارت، کتابخانهٔ PDF محلی و قابلیت‌های اختیاری AI را در یک برنامه گرد می‌آورد.

این مخزن برای بررسی فنی عمومی و درخواست برنامهٔ Codex for Open Source آماده شده است. **مَدار پروژه‌ای مستقل است؛ محصول رسمی OpenAI نیست و ادعای وابستگی یا تأیید OpenAI ندارد.** سورس اصلی مَدار تحت [مجوز MIT](LICENSE) منتشر می‌شود؛ اجزای ثالث مجوزهای مستقل خود را حفظ می‌کنند.

## ساختار

- `app/` — کد HTML/CSS/JavaScript و سرویس محلی Python و ماژول‌های PDF/کتابخانه.
- `repair453/` — overlay و نصاب تاریخی v4.53.
- `repair454/` — overlay مسیر ذخیره‌سازی v4.54 و به‌روزرسان یک‌کلیکی با هش دقیق برای نسخه‌های شناخته‌شدهٔ v4.49 تا v4.53.
- `oneclick/` — سورس launcher ویندوز x64 و سازندهٔ بسته؛ فایل اجرایی و objectهای کامپایل‌شده عمداً در مخزن نیستند.
- `docs/` — معماری، مرزهای حریم خصوصی و امنیت، وضعیت آزمون‌ها و زمینهٔ درخواست بررسی OpenAI.
- `tests/` — آزمون‌های ایزولهٔ حذف کتاب، مسیرهای ذخیره‌سازی و یکپارچگی payload نسخهٔ v4.54.

## تغییرات شاخهٔ کاری v4.54

- داشبورد خلاصهٔ یادگیری.
- رابط فارسی راست‌به‌چپ و معماری ثبت داده‌های یادگیری محلی.
- بازکردن PDF و مدیریت نسخهٔ ذخیره‌شدهٔ محلی.
- در «کتاب‌های من»، بازکردن و حذف نسخهٔ مدیریت‌شده؛ فایل اصلی خارج از پوشهٔ کتاب‌ها حذف نمی‌شود.
- API محلی حذف کتاب با بررسی Origin و تأیید صریح.
- تشخیص ریشهٔ نصب از پوشهٔ والد `App`؛ پوشه‌های `Data`، `Books`، `Logs`، `Backups` و `Reports` زیر همان ریشه باقی می‌مانند.
- به‌روزرسان یک‌کلیکی با پذیرش فقط هش دقیق نسخه‌های v4.49 تا v4.53؛ پیش از جایگزینی از چهار فایل برنامه پشتیبان می‌گیرد، مسیر فعال `Data` و `Books` را بررسی می‌کند و در شکست آزمون سلامت، فایل‌های برنامه را بازمی‌گرداند.
- سوابق آموزشی و کتاب‌های مدیریت‌شده جابه‌جا، حذف یا بازنویسی نمی‌شوند. نسخهٔ v4.48 و نسخه‌های ناشناخته یا دست‌کاری‌شده به‌جای حدس‌زدن، با توقف امن رد می‌شوند.

برخی مسیرهای آموزش AI و اجرای نهایی روی ویندوز هنوز آزمون کامل نشده‌اند؛ [وضعیت آزمون‌های v4.54](docs/TEST_STATUS_v4.54.md) را ببین.

## پیش‌نیازها، نصب و اجرا از سورس

- **پیش‌نیازها:** Python نسخهٔ ۳.۱۰ یا بالاتر (در CI از Python 3.13 استفاده می‌شود)؛ Node.js نسخهٔ ۲۲ تنها برای بررسی اختیاری سینتکس جاوااسکریپت لازم است.
- **اجرای سرویس محلی (بر اساس سورس تأییدشده):**
  ```bash
  git clone https://github.com/Amin-Sheikhy/Madar.git
  cd Madar
  python app/madar_launcher.py --server
  ```
  سرویس به‌صورت پیش‌فرض روی `127.0.0.1:8765` اجرا می‌شود (با `MADAR_PORT` قابل تغییر است). برای تعیین ریشهٔ نصب و داده از `MADAR_HOME` استفاده کن. اگر لانچر در ساختار نصب‌شدهٔ `<MADAR_HOME>/App/madar_launcher.py` باشد، پوشهٔ والد `App` به‌عنوان ریشه تشخیص داده می‌شود. هنگام اجرای مستقیم از سورس (`app/`)، مسیر پیش‌فرض ویندوز `%LOCALAPPDATA%/Madar` است (و اگر `LOCALAPPDATA` موجود نباشد، `~/AppData/Local/Madar`) تا داده‌های اجرایی وارد مخزن عمومی نشوند. پوشه‌های `Data`، `Books`، `Logs`، `Backups` و `Reports` زیر همین ریشه قرار می‌گیرند؛ `MADAR_DATA_DIR` مسیر `Data` را جداگانه قابل‌تغییر می‌کند. هیچ دادهٔ آموزشی شخصی داخل این مخزن قرار داده نشده است.
- **اجرای آزمون‌ها:**
  ```bash
  python -m compileall -q app tests repair453 repair454
  python -m unittest discover -s tests -v
  ```

مَدار برای expose شدن روی شبکهٔ محلی یا اینترنت طراحی نشده است. قبل از اجرا، [ملاحظات حریم خصوصی و امنیت](docs/PRIVACY_SECURITY.md) را مطالعه کن.
