# OpenAI / Codex for Open Source review context

Madar is an independent personal software project: a Persian-first, local-first learning and research workspace for Windows. This repository makes a curated source snapshot available for public technical review.

The project owner is seeking consideration through the **Codex for Open Source** program, if the project is eligible. This repository and document are context for an application; they are **not** a submitted application, support ticket, or statement that OpenAI has approved access.

## Program context (checked 2026-11-15)

OpenAI's public program page describes support for maintainers of active open-source projects. Its published selection signals include meaningful usage, broad adoption, ecosystem importance, and evidence of active maintenance. Applications are reviewed on a rolling basis; the program page says applicants whose project does not neatly fit may still apply and explain its importance.

The published program benefits for selected maintainers include six months of ChatGPT Pro (which includes Codex), conditional access to Codex Security, and API credits for qualifying project workflows. Selection is not guaranteed.

- Program details: https://developers.openai.com/community/codex-for-oss
- Application form: https://openai.com/form/codex-for-oss/

The form currently asks for a public GitHub profile and public repository URL, maintainer role, a short explanation of why the repository qualifies, OpenAI Organization ID, intended API-credit use, and other details. Some text fields have 500-character limits.
