# Madar v4.56 — SIWC reauthorization and build identity repair

این بسته برای نصب تأییدشدهٔ v4.55 طراحی شده است.

## تغییرات
- هویت نسخه از فایل `App/BUILD.txt` خوانده می‌شود؛ API سلامت، سربرگ، عنوان پنجره و پاورقی داشبورد از یک شناسهٔ واحد استفاده می‌کنند.
- نسخهٔ ثابت v4.52 از نشان سربرگ داشبورد حذف می‌شود.
- حافظهٔ نهان Service Worker با کلید v4.56 تازه‌سازی می‌شود.
- اگر نوسازی توکن SIWC با `HTTP 400 / invalid_grant` رد شود، فقط توکن‌های ردشده از مخزن DPAPI حذف می‌شوند. شناسهٔ مشتری صادرشده، شناسهٔ حساب و راهنمای ورود حفظ می‌شوند تا ورود دوباره با همان حساب و همان client ID انجام شود.
- پنل اتصال پس از خطای قطعی، دکمهٔ ورود مجدد را نشان می‌دهد و وضعیت داشبورد نیز به‌روز می‌شود.

## نصب و حفاظت
- تنها فایل اجرایی `Madar456-OneClick-D.exe` اجرا می‌شود.
- نصب‌کننده فقط شش فایل برنامه را جایگزین می‌کند: `BUILD.txt`، `chatgpt_plan.py`، `madar_ai_server.py`، `chatgpt_ui.js`، `dashboard_v452.js` و `sw.js`.
- پیش از جایگزینی، هش دقیق نسخهٔ نصب‌شده بررسی و از فایل‌های برنامه پشتیبان تهیه می‌شود.
- پوشه‌های `Data` و `Books` خوانده می‌شوند اما تغییر نمی‌کنند.
- هیچ گزارش یا داده‌ای خودکار بارگذاری نمی‌شود.
- آزمون فهرست مدل‌ها فقط فراداده را می‌خواند و درخواست تولید پاسخ نمی‌فرستد.
- در صورت شکست کنترل محلی، فایل‌های برنامه از پشتیبان بازگردانده می‌شوند.
